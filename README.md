# Gerador de Contrato de Locação Residencial

Sistema para preenchimento automático de contratos de locação residencial para a NSW Administradora de Bens Ltda.

## Arquivos

- `index.html` - Interface do formulário e contrato
- `style.css` - Estilos do aplicativo
- `script.js` - Lógica de geração do contrato

## Como Usar

1. Abra o arquivo `index.html` em qualquer navegador
2. Preencha os dados do locatário
3. Preencha os dados do imóvel
4. Configure os dados do contrato (datas, valores, etc.)
5. Clique em "Gerar Contrato"
6. Use "Imprimir / Salvar PDF" para exportar

## Funcionalidades

- Formatação automática de CPF
- Conversão de valores por extenso
- Cálculo automático de data de término
- Formatação de datas
- Impressão direta em PDF
- Layout responsivo
